# Interactive planning

Goal: turn a rough idea into a high-level plan and then a step-by-step spec detailed enough to hand to a developer.

Ask one question at a time. Each question builds on the previous answer. Work iteratively and dig into every relevant detail — requirements, constraints, edge cases, and what is explicitly out of scope.

Only one question per turn. If you genuinely must ask more than one sub-question, number each one (1, 2, 3). If a sub-question offers a choice, letter the options (A, B, C) so I can answer with minimal typing.

Do not begin implementing while planning. When the spec is complete, write it out in full.
